# my-portfolio

[![CI](https://github.com/wegoagain-dev/my-portfolio/actions/workflows/ci.yml/badge.svg?branch=main)](https://github.com/wegoagain-dev/my-portfolio/actions/workflows/ci.yml)

Personal DevOps and Kubernetes portfolio site built with Astro.

## Local setup (reproducible)

```bash
nvm use
npm ci
npm run build
```

If dependencies ever get out of sync:

```bash
npm run reinstall
```
